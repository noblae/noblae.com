# Gallery images

Any image in this folder (.jpg, .png, .gif, .webp) appears on the Images page
automatically, about a minute after it's added.

To add one on GitHub: open this folder, click **Add file → Upload files**,
drop the photos in, and click **Commit changes**.

Images uploaded here show after the ones added through the admin page, in
alphabetical order by file name, and without captions. For captions, use the
admin page (noblae.com/admin.html) instead.
