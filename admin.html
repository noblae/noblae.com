Local test mode

You opened this page from your own computer, so nothing goes to the live site. Uploads are saved into this project folder instead. Any token works here, e.g. "test".

Connect this device

This only has to be done once on each phone or computer you use.

  1. Open GitHub → new access token (signed in as the account that owns the site).
  2. Name it "noblae admin" and set an expiration.
  3. Under Repository access, pick Only select repositories → noblae/noblae.com.
  4. Under Permissions → Contents, choose Read and write.
  5. Click Generate token, copy it, and paste it below.

Add images

On the site now

Newest first. Images added straight to the images/gallery folder on GitHub show at the end. Click × to remove an image from the site.

Add a poem

Select words and click a button (or press Cmd+B / Cmd+I / Cmd+U). In the text it shows as **bold**, *italic*, __underline__ and ~~strikethrough~~.

On the site now

Edit changes a poem's title, date or text. Delete removes it from the site. The Poetry page runs newest first: any save puts it in date order, or press the button to do only that.

Add an essay

Select words and click a button (or press Cmd+B / Cmd+I / Cmd+U). In the text it shows as **bold**, *italic*, __underline__ and ~~strikethrough~~.

On the site now

Edit changes an essay's title, date or text. Delete removes it from the site.

Add a video

Copy the link from YouTube's Share button (or the address bar) and paste it above. Shorts links work too.

On the site now

Edit changes a video's link, title or date. Delete removes it from the site (not from YouTube).

On the home page now

These poems, essays, images and videos appear on the home page, top to bottom, with no dates shown. Use the arrows to reorder, then press Save. The Poetry page is separate and always stays in date order. Once you save, new posts do not show on the home page until you add them here.

Not on the home page

Press Add to put a piece at the bottom of the home page, then move it where you want it.
